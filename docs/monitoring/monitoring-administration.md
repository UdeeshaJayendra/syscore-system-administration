# Monitoring Administration

## Overview

This lab demonstrates basic Linux system monitoring techniques used by system administrators.

The monitoring activities cover:

- CPU and system information
- Memory usage
- System load
- Running processes
- Disk usage
- Inode usage
- Filesystems and mount points
- Disk devices
- Service health
- Listening ports
- Network interfaces
- Routing
- System logs
- SSH logs
- Nginx logs
